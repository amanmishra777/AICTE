# Aman - E-Commerce Customer Behavior Analysis

This project is a personal data analysis study focused on customer behavior in an online retail environment. I built it to explore customer spending patterns, loyalty membership trends, satisfaction levels, and purchase activity using a structured dataset.

## Project Overview
The main goal is to understand how demographics and membership status influence shopping behavior. The analysis highlights the relationship between customer profile, loyalty tier, rating quality, and overall satisfaction.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
The project uses a customer behavior dataset that captures information such as age, gender, city, membership type, total spend, items purchased, average rating, discount usage, days since last purchase, and satisfaction level.

## Project Files
- `Aman_EcommerceCustomerBehavior.ipynb` — notebook with the full analysis and visualizations
- `data/ecommerce_customer_behavior.csv` — dataset used for the study
- `requirements.txt` — Python dependencies required to run the project

## Setup Instructions
1. Open the project folder in VS Code or Jupyter Notebook.
2. Install the required libraries by running:
   `pip install -r requirements.txt`
3. Open the notebook and run all cells in order.

## Key Insights
- Gold and Silver members usually spend more than Bronze members.
- Higher average ratings are associated with better customer satisfaction.
- Discount usage influences buying behavior and customer engagement.
- City-level and membership-level differences help identify target marketing opportunities.
